Welcome to QBasic

QBasic is a simple and powerful programming language. It is the perfect starting point for beginners who want to learn how code works without getting overwhelmed by complex setup.

Your First QBasic Program

Writing a basic text output program takes just one line of code:

REM My First Program
CLS
PRINT "Hello, World!"
END

This code clears the screen (CLS), prints a message, and ends the program.

What You Will Learn

  • How to display text on the screen.
  • How to use variables to store data.
  • How to make decisions using IF/THEN statements.
  • How to create loops for repeating tasks.
