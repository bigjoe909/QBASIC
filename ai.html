What is QBasic?

QBasic is an easy-to-learn programming language created by Microsoft in 1991. It is based on the older BASIC language. It is a great tool for beginners to understand how computers execute instructions step by step.The full meaning of QBASIC stands for quick beginners all-purpose symbolic instruction code. Meaning is a quick and easy to learn programming language for beginners.

Your First Program: PRINT

The PRINT command tells the computer to show text on the screen. In QBasic, commands are often written in uppercase letters.

REM This is a comment
PRINT "Hello, World!"
PRINT "Welcome to QBasic coding."
In QBasic REM also known as remark is used to write down comment in a program, comment are sentence which explain each step in a program code or tell user what the code is all about, you can also use this sign (')apostrophy in QBasic for comment instead of REM.

Using V/ariables

You can ask the user to type something using the INPUT command and save their answer inside a variable.

Learning QBasic: Variables and IF/THEN Statements

Introduction to QBasic

Welcome! This guide teaches you two fundamental concepts in QBasic programming: storing data in variables and making decisions using IF/THEN statements.

What is a Variable?

A variable is like a labeled box in computer memory that holds information. You can change the contents of the box anytime. In QBasic, you create a variable simply by giving it a name and assigning a value to it.

Types of Variables

  • Numeric Variables: Store numbers for math operations (e.g., age = 15).
  • String Variables: Store text. These names must end with a dollar sign ($) and the text must be in quotation marks (e.g., name$ = "Alex").

Making Decisions with IF/THEN

An IF/THEN statement lets your program make choices. It checks if a condition is true. If it is true, the program runs a specific block of code.

You can also use ELSE to tell the program what to do if the condition is false.

Complete QBasic Example

Here is a complete program combining variables and decision-making. It checks if a user is old enough to vote.

' QBasic Voting Eligibility Program
CLS ' Clears the screen

' 1. Storing data in variables
LET userName$ = "Sam"
LET userAge = 19

' 2. Making a decision
IF userAge >= 18 THEN
    PRINT userName$; ", you are eligible to vote!"
ELSE
    PRINT userName$; ", you are too young to vote."
END IF

How the Code Works:

  • CLS clears any old text from the output screen.
  • userName$ holds the text "Sam", and userAge holds the number 19.
  • The IF statement checks if 19 is greater than or equal to 18. Since it is true, the program prints the first message and skips the ELSE part.

Test Your Knowledge

What would the program print if you changed userAge = 14?

Answer: It would skip to the ELSE block and print: Sam, you are too young to vote.
